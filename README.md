# PayFURL Extension for WooCommerce

Takes payments in WooCommerce's checkout through [payFURL](https://payfurl.com/): cards with Click to Pay, PayPal,
Google Pay, Apple Pay, PayTo, PayID and more, routed to the payment gateways connected to your payFURL account.

Install it from WordPress.org: [PayFURL Extension for WooCommerce](https://wordpress.org/plugins/payfurl-extension-for-woocommerce/).
Setup, requirements and the FAQ are in [`readme.txt`](readme.txt), and what changed in each version in
[`CHANGELOG.md`](CHANGELOG.md).
